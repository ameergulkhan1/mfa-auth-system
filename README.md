# MFA Authentication System

A full-stack Multi-Factor Authentication (MFA) system built with FastAPI, React, and PostgreSQL to demonstrate secure user authentication and account protection.

## Key Features

- **SMS/PIN Verification:** Six-digit verification codes with expiration and attempt limits.
- **TOTP Authentication:** Time-based one-time passwords using authenticator apps such as Google Authenticator.
- **Secure Authentication:** Server-side verification and protection against brute-force attacks.
- **Analytics Dashboard:** Monitor authentication activity and security metrics.
- **Full-Stack Architecture:** FastAPI backend, React and Redux frontend, and PostgreSQL database.

## Tech Stack

- **Backend:** Python, FastAPI
- **Frontend:** React, Redux
- **Database:** PostgreSQL
- **Authentication:** SMS/PIN, TOTP
- **Tools:** Git, GitHub

## Project Goals

Demonstrate practical authentication security, verification workflows, account protection, and authentication monitoring.
